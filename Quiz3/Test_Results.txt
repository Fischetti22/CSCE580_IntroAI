======================================================================
ANALYSIS
======================================================================

BFS (Breadth-First Search):
  - Explores nodes level by level
  - Guarantees optimal solution (shortest path)
  - Uses more memory (stores all nodes at current level)
  - FIFO queue implementation

DFS (Depth-First Search):
  - Explores as deep as possible before backtracking
  - Does NOT guarantee optimal solution
  - Uses less memory (stores path from root)
  - LIFO stack implementation

Key Differences Observed:
  - BFS finds shortest solution paths
  - DFS may find longer paths but sometimes faster
  - Both algorithms find solutions when they exist
  - Both correctly identify impossible cases (2M, 3C)
