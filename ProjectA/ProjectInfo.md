## Results / Notes

Learning Process: The game clearly demonstrated how trial-and-error plus structured updates mirror the process of machine learning. Each attempt provided useful feedback that guided the next guess, much like gradient descent updates weights in a neural network.

Manual vs. AI Performance: As a human player, progress came from intuition and adjusting guesses incrementally. However, the AI’s formula-based updates consistently reduced the gap to the target more quickly, often solving the puzzle in fewer attempts.

Backpropagation in Action: The exercise reinforced three core principles of backpropagation: (1) learning from feedback, (2) making proportionally larger updates when errors are larger, and (3) updating each parameter (digit) individually based on its multiplier.

Difficulty & Engagement: Starting with a one-digit passcode was straightforward, while longer codes highlighted the challenge of managing multiple variables. The shifting multipliers kept the task dynamic, preventing simple memorization.

Practical Insight: The assignment provided a tangible, gamified explanation of how algorithms like backpropagation operate in widely used AI models (e.g., ChatGPT or TikTok recommendations). It bridged theory and practice in a way that was intuitive and engaging.
