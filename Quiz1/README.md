## Quick start
1. Create/activate a Python 3.9+ environment.
2. Install basics (if a requirements file is not present):
   ```bash
   pip install jupyter numpy pandas matplotlib scikit-learn
   ```
3. Open each notebook in `code/` and review the first config cell. Paths should point to files in `data/` and save to `figures/`.
4. Restart & Run All.
